# dndn (تطبيق البائع)
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (مع مجلد .github).
2. افتح تبويب Actions ← Build APK ← انتظر حتى ينتهي (3-6 دقائق).
3. ادخل على آخر تشغيل ← Artifacts ← حمّل APK ← فك الضغط وثبّت app-debug.apk على هاتف البائع.
4. افتح التطبيق، اقبل الإشعارات واستثناء البطارية. اضغط ⚙ واكتب اسمك الذي يظهر للزبائن.
يعمل بدون إنترنت. يجب أن يكون هاتفك متصلًا بالراوتر (أو يعمل كنقطة اتصال/Hotspot).
